Research

Undergraduate Researcher — WireBend-Kit

UW Programmable Matter Lab · Advisor: Prof. Martin Nisser

Jan 2026 — Present

I joined Professor Martin Nisser's Programmable Matter Lab to work on WireBend-Kit, a machine that automatically bends wire into 3D wireframes. My main contribution was building a closed-loop feedback system: I added electronic sensing to estimate the actual bend angle after each actuation, then fed that error back into the control loop to apply a correction pass. Along the way I consolidated firmware across multiple microcontrollers down to a single board and rewrote the Python GUI to be more intuitive for iterative testing. It's been a fascinating introduction to hardware-in-the-loop control systems, and I am excited to continue exploring similar systems.

Projects

Pipelined ARM CPU

I designed a pipelined ARM processor in Verilog from scratch — five pipeline stages, hazard detection and forwarding logic, and a branch predictor. The trickiest part was getting hazard resolution right across load-use dependencies. I synthesized and tested it on an FPGA using Quartus, and spent a lot of time in simulation traces figuring out exactly which edge cases the forwarding network was missing.

Verilog FPGA Quartus ARM

Bottom-Fed Turret Overhaul

I rearchitected the ARUW competition robot's ball-feeding system from a top-fed to a bottom-fed layout. The original design stacked the hopper above the turret, which raised the center of gravity and made the yaw axis oscillate during fast moves. Moving the feed underneath let me sit the turret's center of gravity directly over the yaw axis — aiming stability jumped immediately. I also redesigned the minor turret, dropping its weight 41% while expanding the range of motion.

SolidWorks Mechanical Design DFM RoboMasters

Custom Robot Controller

A purpose-built USB HID controller I designed for operating the ARUW robot — a replacement for using a keyboard during competition. Twenty keys on a 4×5 matrix, running on an ATmega32U4 that enumerates directly as a keyboard on the host PC. I designed the schematic and PCB in Altium, wrote the matrix-scan firmware in C, and flashed the bare chip using Arduino as ISP rather than going through a bootloader. It's currently deployed and used for live robot control.

ATmega32U4 C / Arduino Altium USB HID PCB Design

Desktop Reminder Buddy

A physical ambient calendar display next to my monitor. ESP32 firmware in C handles I²C display comms and UART data ingestion from a Python host script. The core challenge: a parser that filters and truncates event strings within a fixed-width display buffer.

C ESP32 Python I²C / UART

Automated soil moisture monitoring with a watering relay. FreeRTOS on ESP32 wakes on a 15-minute timer, samples the ADC, and triggers a relay below threshold. A startup calibration routine was essential — capacitive soil sensors drift a lot.
