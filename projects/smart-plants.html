Smart Plants

Automated soil moisture monitoring with a relay-driven watering system — ESP32, FreeRTOS, and capacitive sensing.

C FreeRTOS ESP32 ADC Embedded Systems

Overview

My plants kept dying because I'd forget to water them for a week and then overwater them trying to compensate. The solution was a system that measures soil moisture on a regular schedule and triggers the pump when it's actually needed — not when I happen to remember.

The firmware runs on FreeRTOS, which gave me a natural way to structure the periodic sensing, control logic, and any future display or connectivity tasks as separate concurrent tasks with well-defined priorities.

How it works

Sensing

Soil moisture is measured with a capacitive sensor connected to the ESP32's ADC. Capacitive sensors measure the dielectric constant of the soil, which changes with water content — as opposed to resistive sensors that pass current through the soil and corrode quickly. The ADC reading is a 12-bit value that needs to be mapped to a meaningful moisture percentage, which is where calibration comes in.

FreeRTOS task structure

The firmware is organized into three tasks. A timer task wakes on a 15-minute interval and signals the sensing task. The sensing task takes an ADC reading, applies the calibration curve, and decides whether to trigger the relay. A third task is reserved for a display interface that's currently in progress.

Using FreeRTOS for what's essentially a simple loop might seem like overkill, but it made adding features — like a future Wi-Fi task for remote logging — straightforward without restructuring the whole program.

Calibration

Capacitive moisture sensors drift significantly between batches, and the relationship between ADC value and actual moisture percentage depends on soil type. At startup, the firmware runs a two-point calibration: it reads the sensor in dry air (0% moisture) and in a water-saturated sample (100% moisture), stores those endpoints, and uses linear interpolation for everything in between. This takes about 30 seconds and makes the readings meaningful regardless of sensor or soil variation.

Key challenges

The biggest problem was ADC noise. The ESP32's internal ADC is notoriously noisy, especially at the edges of its range (near 0V and near 3.3V). Raw readings from the moisture sensor would swing by 50–100 counts between samples, which was enough to trigger false watering events. I added a sliding window average over eight samples and a hysteresis band around the watering threshold — the relay only triggers when the smoothed reading drops below the threshold, and only resets when it rises meaningfully above it.

Getting the relay timing right was also trickier than expected. Running the pump for too long floods the pot; too short and the soil barely registers the moisture increase before the next reading. I ended up tuning the watering duration empirically per-plant based on pot size and how quickly the reading recovers.

What's next

I'm working on adding a small display that shows current moisture level, last watering time, and next scheduled check. A Wi-Fi task for logging readings to a simple dashboard would also be useful — I want to see moisture trends over days to better understand how different plants use water.
